# Практическая работа №2. Инструмент визуализации графа зависимостей для менеджера пакетов

## Этап 1: конфигурация

Обычный запуск с основным конфигом:
```bat
run.bat
```

На этапе 1 программа выводила пять параметров в формате ключ-значение.

## Демонстрация обработки ошибок

В каждом конфиге для проверки параметра изменено только его значение.
В проверке отсутствующего тестового репозитория также включён тестовый режим.

Команда - Ожидаемая ошибка

- `run.bat tests\bad_package.ini` - Имя пакета не может быть пустым
- `run.bat tests\bad_repository.ini` - Некорректный URL репозитория
- `run.bat tests\bad_test_mode.ini` - Некорректное логическое значение
- `run.bat tests\bad_output_file.ini` - Выходной файл должен иметь расширение .svg
- `run.bat tests\bad_ascii_tree.ini` - Некорректное логическое значение
- `run.bat tests\missing_repository.ini` - Файл тестового репозитория не найден
- `run.bat tests\nonexistent.ini` - Конфигурационный файл не найден

В PowerShell запускать с префиксом `.\`,
например: `.\run.bat `.

## Этап 2: сбор прямых зависимостей

В PowerShell запусти из папки проекта:

```powershell
.\run.bat
```

По умолчанию программа анализирует пакет `requests`. В `config.ini`
можно поменять `package` и адрес JSON API в `repository`
(например, `https://pypi.org/pypi`). Требуется доступ к репозиторию.

Программа выводит требования из поля `info.requires_dist` по одному на
строку. Ограничения версий и условия сохраняются, включая зависимости для
дополнений (extras). Условия пока не вычисляются. Если требований нет,
программа выводит «Нет зависимостей». При ошибке выводится её причина.


## Этап 3. Граф зависимостей

Обычный запуск строит граф по метаданным PyPI. Программа хранит его в памяти
как словарь пакетов и их исходящих связей. Обход идёт в глубину с явным
стеком. Повторно встреченный пакет не загружается ещё раз. Если связь ведёт
к пакету в текущем пути обхода, ребро сохраняется и выводится сообщение
о цикле.

Строка вывода содержит пакет, версию из поля info.version и его прямые
зависимости. На рёбрах сохраняются требования версий из info.requires_dist.
Версии берутся из ответов репозитория. Программа не подбирает совместимый
набор версий. Записи с условием extra == пропускаются при обходе, поскольку
в INI нет выбора дополнений. Другие условия сохраняются в исходной строке.

Тестовый репозиторий — JSON-массив ответов PyPI. У каждого пакета те же поля
info.name, info.version и info.requires_dist, что и в ответе JSON API.
Чтобы использовать свой файл, задай его путь в repository, имя начального
пакета в package и test_mode = true.

Команды для демонстрации в PowerShell:

- .\run.bat graph_diamond.ini — общий пакет D у B и C.
- .\run.bat graph_cycle.ini — цикл X → Y → X.
- .\run.bat graph_self_cycle.ini — пакет Z зависит от самого себя.
- .\run.bat graph_leaf.ini — пакет D без зависимостей.
